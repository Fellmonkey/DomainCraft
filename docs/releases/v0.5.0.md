# v0.5.0

## New

- **Bridge composition** — `extends:` builds a chain of layers.
- **Patch field support** in the model.

## Fixed and improved

- Path-like bridge inputs are resolved only against the filesystem — a missing local path is an error, never an `owner/repo` clone.
- Compliance suite strengthened: owner isolation and rate-limit tests, latency thresholds scoped to expected responses.
