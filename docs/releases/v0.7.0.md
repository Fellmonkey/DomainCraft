# v0.7.0

## New

- **`--replace` in the bridge chain** — swap a layer without forking (`persistence=dapper`, `transport=grpc`, …).
- **Layered bridge resolution** — package versions resolved once for the whole chain.

## Fixed and improved

- IR and renderer split into modular files.
- Deterministic output everywhere: sorting via `slices`/`maps`/`cmp` — two runs on the same `domain.yaml` are byte-identical.
